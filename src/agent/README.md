# Agent Core

This directory contains the core agent logic and skills for the Personal Super Agent.

## Skills

The agent operates through Base44's Superagent platform with the following capabilities:

- **Content Planning** — Drafts captions, hashtags, and posting schedules for Facebook & TikTok
- **Email Triage** — Labels and categorizes incoming emails (currently paused)
- **Daily Briefing** — Aggregates calendar, email, market, and tech news into a morning brief
- **Market Analysis** — Nigerian and global market insights
- **Calendar Management** — Meeting prep, conflict detection
- **File Management** — Google Drive read/write operations
- **GitHub Operations** — Repo management, issue tracking

## Identity

The agent's identity, soul, and user profile are managed through Base44's identity system (IDENTITY.md, SOUL.md, USER.md).

## Memory

Long-term memory persists across sessions via Base44's memory system.
